# veXDC Staking — v1

Real-yield `ve` staking for the XDC Network. Users lock XDC/WXDC for whole-week periods and
receive a **soulbound veNFT**; whitelisted dApps commit revenue through immutable adapters, and
that revenue is distributed each weekly epoch pro-rata to snapshotted `ve` weight.

No emissions token. No split/merge. No transfer path.

Implementation of [`veXDC Staking — v1 Architecture Specification` (draft v0.5)](docs/SPEC.md).

See [`docs/`](docs/) for architecture, deployment, operations and security documentation.
